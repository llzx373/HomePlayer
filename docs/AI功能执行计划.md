# AI 功能执行计划

本文把 AI 库管理、翻译与 AI 音轨、画面增强三条路线拆成可执行、可验收、可独立回退的工作包，供后续技术设计和实施排期使用。

当前状态：**待实施**。本文不表示相关能力已经实现，也不表示 `0.3.0-1` 测试版本将包含全部规划内容。版本号只用于后续构建和打包测试，创建 GitHub Release 仍需另行明确决定并推送版本标签。

## 1. 执行原则

1. 不先建设庞大的通用 AI 平台，按垂直闭环逐步交付，每个阶段都产生可验证结果。
2. 库管理优先落地，翻译作为核心差异化能力，画面增强经过技术验证后再产品化。
3. 三条路线共用必要的模型、任务、缓存和诊断基础设施，但不互相绑定发布。
4. 本地处理优先，云端服务按功能、按任务明确授权；默认不上传完整媒体。
5. 不自动处理整个媒体库，不自动覆盖用户元数据，不自动删除磁盘文件。
6. AI 功能关闭时，现有媒体库、字幕和播放行为保持不变。
7. 实时画面增强优先获得播放资源，后台翻译、识别和索引任务在播放时让路。
8. 不支持的能力必须显示原因；模型或 AI 处理失败不能破坏稳定播放路径。

## 2. 第一版范围

三条路线分别收敛为：

- **库管理**：自然语言筛选和 AI 元数据建议，全程可预览、可撤销。
- **翻译**：已有英语文本字幕时，生成中文字幕和单一音色的中文 AI 配音。
- **播放路线**：中文 AI 配音优先支持 HomePlayer 原生（FFmpeg）路线。
- **画面增强**：验证 SDR、常见 8-bit 内容的 AI 超分，默认关闭，保留 Basic/libplacebo 回退。
- **模型分发**：按需下载，不在基础安装包中捆绑全部模型。

第一版明确不做：

- 无字幕电影的完全实时配音；
- PGS/VobSub 位图字幕 OCR；
- 默认克隆演员或其他现实人物声音；
- 自动覆盖用户元数据或自动删除重复文件；
- 大模型直接执行 SQL、脚本或文件操作；
- 默认开启 AI 超分和插帧；
- 在 madVR 等外部输出上伪装支持 HomePlayer AI 渲染；
- 把只支持 SDR 的模型宣称为完整 HDR 增强；
- 账号体系、云同步和强制在线服务。

## 4. M0：冻结范围，建立测试基线

### 目标

避免开发过程中不断加入实时翻译、无字幕识别、多角色配音、HDR 超分等需求，导致第一条功能链无法闭环。

### 执行任务

- [ ] 冻结第 2 节的第一版范围和不做清单。
- [ ] 建立片库样本：电影、剧集、多版本、特别篇、混乱文件名和缺失元数据。
- [ ] 建立翻译样本：外挂字幕、内嵌文本字幕、多人对白、长句、歌曲和无语片段。
- [ ] 建立画面样本：动画、真人、老片、低码率、噪点、文字和快速运动场景。
- [ ] 保存 1 万、5 万条媒体库的搜索与翻页性能基线。
- [ ] 保存普通播放首帧、seek、音画同步和资源占用基线。
- [ ] 保存 Basic/libplacebo 的性能与截图对照。
- [ ] 保存数据库备份、恢复和迁移基线。
- [ ] 明确本地处理、云端授权、日志脱敏和默认不处理全库的隐私边界。

### 交付物

- 已确认的范围和不做清单；
- 可重复使用的测试样本清单；
- 现有性能基线；
- 后续验收使用的媒体库与播放场景。

### 阶段门槛

测试样本和验收场景不完整时，不进入模型选型和性能承诺。

## 5. M1：最小 AI 基础设施

只实现后续工作包立即需要的能力，不提前建设复杂插件生态。

### 5.1 设置与能力状态

- [ ] AI 总开关和各功能开关。
- [ ] 本地/云端服务配置。
- [ ] 模型目录、缓存目录和磁盘配额。
- [ ] 后台任务并发和资源策略。
- [ ] 播放时暂停后台任务。
- [ ] 模型缺失、不可用、下载中和损坏状态。
- [ ] 不可用时显示原因，不出现点击无反应的入口。

### 5.2 模型清单

每个模型记录：

- ID、版本、用途、来源和许可证；
- 文件哈希、大小和运行依赖；
- 输入输出限制；
- 内存、显存和磁盘需求；
- 下载、校验、删除和状态检查。

执行任务：

- [ ] 建立统一模型清单和状态检查。
- [ ] 实现按需下载、哈希校验、失败重试和删除。
- [ ] 将模型和原生依赖纳入哈希、SBOM、许可证和私有依赖检查。
- [ ] 第一版只允许官方审核的模型，不安装任意第三方模型代码。

### 5.3 后台任务系统

统一任务状态：

```text
Queued → Running → Completed
                 → Failed
                 → Cancelled
Paused / WaitingForModel / WaitingForResources
```

任务至少记录：任务类型、媒体标识、输入指纹、参数指纹、模型版本、当前进度、已完成分段、错误、重试次数、更新时间和输出产物位置。

执行任务：

- [ ] 排队、暂停、继续、取消和重试。
- [ ] 有界并发、磁盘预算和超时。
- [ ] 失败分段单独重试。
- [ ] 应用重启后的任务恢复和断点续作。
- [ ] 播放时让路，避免影响首帧、seek 和音画同步。

### 5.4 数据与产物

逻辑上区分：

1. **用户数据**：确认后的元数据、标签、术语表和人工修改的译文，纳入备份。
2. **可重建结果**：生成的字幕、配音、索引和封面候选，可选择备份，默认可以重新生成。
3. **临时缓存**：模型中间结果、抽帧、音频分段和实时推理缓存，可安全清理。
4. **任务记录**：状态、进度、错误和产物引用，用于恢复和诊断。

缓存键至少包含：

```text
源文件指纹
+ 字幕/音轨身份
+ 模型版本
+ 翻译及声音参数
+ 用户术语表版本
```

执行任务：

- [ ] 数据库迁移和读写接口。
- [ ] 产物生命周期、配额和清理。
- [ ] 源文件、字幕、模型和用户参数变化时的失效规则。
- [ ] 备份包含用户确认的数据，临时缓存可以排除并安全重建。

### 5.5 诊断与隐私

- [ ] 记录任务耗时、失败阶段、模型版本和资源使用。
- [ ] 不记录完整媒体内容和云端密钥。
- [ ] 云端发送前展示数据类型和范围。
- [ ] 文件名、字幕和 NFO 文本只作为数据，不能触发工具或命令执行。
- [ ] AI 功能关闭时保持现有行为。

### 验收

- 模型缺失、下载失败、磁盘不足和任务取消均可恢复。
- 应用重启后不会重复生成已完成分段。
- AI 后台任务与媒体库扫描不会互相破坏状态。
- 数据库升级、备份和恢复包含用户确认的数据。
- 普通播放和媒体库功能在 AI 关闭时无回归。

## 6. M2：自然语言找片垂直闭环

### 目标

交付第一条可实际使用的 AI 功能，同时验证服务配置、任务状态、隐私和结果解释机制。

### 执行任务

- [ ] 定义结构化查询协议：搜索文本、库/目录范围、递归、类型、年份、时长、分辨率、编码、观看状态、字幕、音轨、标签、收藏、合集、排序和限制。
- [ ] 校验模型输出，只接受约定字段和枚举。
- [ ] 拒绝 SQL、脚本、未知操作和文件修改指令。
- [ ] 无法识别的条件明确显示，不悄悄忽略。
- [ ] 将结构化查询映射到现有筛选和分页查询。
- [ ] 把解析结果显示为可编辑筛选标签，用户确认后执行。
- [ ] 支持结果播放和加入播放列表，暂不允许一句话批量修改媒体库。
- [ ] 模型不可用时回退普通搜索。

### 验收

- 自然语言结果与相同手动筛选结果一致。
- 每个条件都可见、可修改、可解释。
- 恶意文件名、字幕或查询文本不能生成 SQL 和文件操作。
- 无网络或模型失败不影响普通搜索。
- 大库查询和翻页性能不突破现有基线预算。

## 7. M3：AI 元数据建议与撤销

### 目标

解决真实片库整理问题，但不承担自动改库风险。

### 执行任务

- [ ] 对选定文件、剧集或目录生成标题、年份、类型、季集、特别篇、合集、多版本和 TMDB 候选建议。
- [ ] 根据元数据生成标签与合集建议。
- [ ] 建议与正式元数据分开存储，记录原值、建议值、依据、置信度和审核状态。
- [ ] 实现修改前后差异、单条/整剧/批量接受、编辑后接受和拒绝。
- [ ] 拒绝后不再重复提示相同建议。
- [ ] 实现操作历史与撤销。
- [ ] 接受后复用现有媒体库更新逻辑，不建立平行的剧集和标签体系。

### 验收

- 不自动覆盖用户手动编辑字段。
- 不接受建议就不会改变正式元数据。
- 批量操作可撤销，重启后历史仍正确。
- 文件离线、TMDB 不可用和模型失败不会误删或误匹配。
- 多版本整理只改变展示关系，不操作磁盘文件。

阶段交付：**AI 片库助手**。

## 8. M4：英文字幕到中文字幕

先独立验证翻译链路，不同时引入语音合成和正式播放同步。

### 执行任务

- [ ] 支持外挂和内嵌文本字幕，暂不处理位图字幕 OCR。
- [ ] 无字幕时明确提示需要后续语音识别能力。
- [ ] 清除样式标记和重复文本，合并被拆散的句子。
- [ ] 保留原始 cue、译文和时间轴之间的可追溯映射。
- [ ] 区分对白、歌曲和可疑噪声文本。
- [ ] 按场景或有限上下文窗口翻译。
- [ ] 支持影片级和剧集级术语表。
- [ ] 支持忠实和自然口语两种初始风格。
- [ ] 对照显示原文和译文，支持单句修改、术语修改和局部重译。
- [ ] 保存或导出生成的中文字幕产物。
- [ ] 字幕、术语和模型变化时按范围失效，不重复翻译未变化分段。

### 验收

- 每条译文都能映射回原始字幕和时间区间。
- 人工修改不会被后台任务覆盖。
- 取消、重启和局部重试不会产生重复或错位 cue。
- 人名和术语在整集、整剧中保持一致。
- 翻译失败不影响原字幕选择和播放。

阶段交付：可用的 **AI 中文字幕**，作为中文配音的质量门禁。

## 9. M5：生成中文配音产物

本阶段只生成和试听配音，不接入正式播放，先验证声音与时间轴。

### 执行任务

- [ ] 接入语音合成服务，第一版使用单一中文音色。
- [ ] 支持语速、音量、按句生成、取消和重试。
- [ ] 保存模型、声音和参数版本。
- [ ] 按原字幕时间轴生成音频分段。
- [ ] 优先利用自然停顿适配中文时长。
- [ ] 限制最大语速，超长句允许调整译文，禁止误差持续累积。
- [ ] 提供原文、译文、原始时间段和中文音频对照试听。
- [ ] 支持单句重新生成、语速调整、延迟调整和术语修订。
- [ ] 试听不占用或干扰主播放器。
- [ ] 生成完整或分段的 AI 音轨产物，并记录分段映射。

### 验收

- 每句配音与原始时间段对应。
- 不出现中文持续超前或落后的累计漂移。
- 单句重新生成不破坏其他分段。
- 歌曲、空白和无对白段落不被无意义配音填满。
- 模型或声音参数变化不会误用旧缓存。

## 10. M6：AI 音轨接入正式播放

当前状态：已实现批量配音和边播边生成的实时配音。实时配音在开启、seek 和换音轨后缓冲约 5 秒再继续播放，合成跟不上时自动回退原声；按说话人区分音色尚未接入实时链路。

这是翻译路线风险最高的阶段，单独实施和验收。

### 背景约束

现有外挂音轨只在 LAV 路线完成，Native 路线尚未支持，且 LAV 外挂自动解码链不使用 HomePlayer 音频增强。因此第一版不简单复用现有外挂音轨功能，而是在 Native/FFmpeg 路线的应用音频管线中接入 AI 音频源和混音。

### 执行任务

- [ ] 接入原声音频、中文配音音频和混音控制。
- [ ] 支持中文音量、原声音量和对白时自动压低原声。
- [ ] 在音轨菜单提供原声和中文 AI 配音，并记住每文件选择。
- [ ] 接入暂停、恢复、seek、连续 seek、倍速、切集和自动连播。
- [ ] 接入音轨切换和音频延迟。
- [ ] 按 Session/Epoch 丢弃旧时间线配音，禁止 seek 后播放旧剧情音频。
- [ ] 接入音量归一化、夜间模式、音频设备变化和 WASAPI 缓冲恢复。
- [ ] 未支持路线显示原因，AI 音轨未生成完整时显示覆盖范围。
- [ ] seek 到未生成区域时明确等待或提示，不播放陈旧配音。

### 必测操作序列

```text
生成配音
→ 播放
→ 暂停/恢复
→ 连续 seek
→ 切换原声/中文
→ 调整延迟
→ 1.25/1.5 倍速
→ 下一集
→ 重启并恢复偏好
```

### 验收

- 无旧配音残留和持续音画漂移。
- 无切换爆音和明显重复播放。
- AI 音轨失败可立即回到原声。
- 普通音轨、外挂音轨和音频增强行为无回归。
- 长时间播放无持续内存和句柄增长。

阶段交付：**中文 AI 配音 Beta**。

## 11. M7：AI 超分技术验证

本阶段是技术门禁，不以“模型能运行”作为通过标准。

### 执行任务

- [ ] 对候选运行时和模型做最小集成验证。
- [ ] 固定 SDR 8-bit 测试集，与 Basic/libplacebo 对照。
- [ ] 测量单帧处理时间、实际丢帧、首帧和 seek 增量。
- [ ] 测量 GPU、显存、CPU 和额外拷贝。
- [ ] 测量连续播放资源趋势。
- [ ] 对真人细节、动画线条、画面文字、噪点、胶片颗粒、快速运动和场景切换做视觉对照。
- [ ] 验证 D3D11 输入输出、纹理生命周期和设备重建。

### 决策门槛

- 有明确视觉收益且目标硬件能稳定实时运行，进入 M8。
- 只有部分硬件可用时，限制支持矩阵并明确原因。
- 没有稳定收益或回退不可靠时，暂停产品化并保留实验结论。
- 不用平均处理时间掩盖 P95/P99 超时和持续丢帧。

## 12. M8：AI 超分产品化

### 执行任务

- [ ] 作为 HomePlayer Renderer 的可选处理阶段接入。
- [ ] 提供关闭、性能、平衡和高质量档位。
- [ ] 首版只开放通过验证的输入格式和色彩范围。
- [ ] 字幕在最终输出分辨率呈现，不随低分辨率画面一起放大。
- [ ] 按文件保存偏好，默认关闭。
- [ ] 显示不支持的外部输出、HDR/像素格式、模型缺失、性能不足和实际回退原因。
- [ ] 处理 seek、动态分辨率、跨屏、设备重建和截图语义。
- [ ] 提供原画面/增强画面对比入口。

### 验收

- 超分不改变音画同步。
- 回退 Basic/libplacebo 不需要重开文件。
- 不发生未声明的每帧 GPU→CPU 回读。
- seek 和设备重建后不显示旧帧。
- 截图能说明是否包含 AI 处理结果。
- 真实媒体与长稳测试无持续显存、内存和句柄增长。
- madVR 等外部输出不会伪装支持。

阶段交付：**AI 画面增强实验版**。

## 13. 后续扩展及依赖

1. **无字幕中文配音**：依赖语音识别、说话人区分、识别文本编辑和 M6 播放链路。
2. **边播边译**：依赖稳定预生成、分段缓存、AI 缓冲状态和资源调度，不直接跳到完全实时。
3. **多角色和情绪配音**：依赖说话人管理、角色音色配置和剧集术语表。
4. **双语学习、解说、前情回顾和无障碍描述**：依赖 AI 音轨框架；前情回顾还依赖观看进度和内容摘要。
5. **自动标签、合集和推荐**：依赖自然语言查询与元数据建议，推荐优先使用本地规则。
6. **台词、摘要和场景搜索**：依赖字幕或语音识别文本与统一内容索引；画面语义搜索另需抽帧和视觉模型。
7. **老片修复**：依赖超分产品化和前后对比体系。
8. **AI 插帧**：最后单独立项，因为它涉及调度器、时间戳、逐帧、截图和音画同步，不是超分的普通选项。

## 14. 三条路线的协同

- 语音识别文本同时服务中文配音、台词搜索、摘要和场景定位。
- 剧集术语表同时服务元数据、字幕翻译和中文配音。
- 内容索引同时服务媒体库搜索和播放时间戳跳转。
- 实时画面增强优先获得 GPU，后台翻译、识别和索引自动让路。
- 文件、字幕、模型和术语变化分别触发必要的缓存失效，避免无关的全片重算。

## 15. 每个工作包统一完成标准

每个阶段都应满足以下条件，不能只以“代码能编译”为完成：

- [ ] 功能开关关闭时无行为变化。
- [ ] 数据库迁移、备份和旧版本升级经过验证。
- [ ] 模型缺失、任务取消、磁盘不足和应用重启有明确行为。
- [ ] 单元测试覆盖解析、状态、缓存键和时间轴逻辑。
- [ ] 播放相关功能使用虚拟时钟或虚拟输出覆盖竞争场景。
- [ ] 使用真实媒体完成用户原始场景，而不只验证接口调用。
- [ ] `dotnet test HomePlayer.slnx -c Release` 通过。
- [ ] `dotnet build src/HomePlayer.App/HomePlayer.App.csproj -c Release` 通过。
- [ ] 性能结果包含失败、取消和无法观测项，不只保留成功样本。
- [ ] 不支持的能力如实展示，稳定路径始终保留。
- [ ] 更新相关规划、能力和诊断文档，不留下描述旧行为的注释。
- [ ] 检查构建和测试产生的新文件，不提交临时日志、缓存和测试输出。

## 16. 实施前已采用的默认决策

后续技术设计如需改变这些决策，应先说明影响范围，再调整本文：

1. 本地优先，云端按任务可选。
2. 模型按需下载，不塞进基础安装包。
3. 翻译首版支持英语文本字幕，不支持无字幕和位图字幕。
4. 配音首版仅支持 Native/FFmpeg，其他路线后续接入。
5. 超分首版限定 SDR 8-bit 和通过验证的硬件矩阵，默认关闭。
6. 推荐发布顺序：AI 片库助手 → AI 中文字幕 → 中文 AI 配音 Beta → AI 超分实验版。
7. `0.3.0-1` 仅作为后续打包测试版本；普通 `main` 分支推送只运行 CI，不创建 GitHub Release。
