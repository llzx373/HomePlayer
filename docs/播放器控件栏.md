## 1. 现在什么样

正在播放页是 `src/HomePlayer.App/Pages/PlayerPage.xaml`，底部 `ControlsBar` 三行：进度条、文字按钮行、状态文字。

当前按钮行：

| 左 | 打开、上一个、播放/暂停、下一个、停止 | 文字按钮 |

## 2. 目标

1. 把文字按钮改成图标按钮，中文进 Tooltip 和 `AutomationProperties.Name`。
2. 按经典播放器分区：走带在左，时间在进度条两端，音量和窗口类在右。
3. 栏上出现的每个按钮都有对应能力。以前引擎没接的（倍速、音轨、字幕、截图、下一帧、置顶、画面比例）这次一起做。
4. LAV 和 FFmpeg 两条引擎行为尽量一致。某条引擎暂时做不到的，按钮禁用并在 Tooltip 说明，不静默无效。

## 5. 倍速

### 5.1 接口

`IPlaybackEngine` 增加：

```csharp
double Rate { get; }
void SetRate(double rate);
```

合法范围夹紧到 `[0.5, 2.0]`。`PlaybackController` 保存当前倍率，打开引擎后立刻 `SetRate`。切文件时控制器把倍率重置为 `1.0` 再打开。

### 5.2 LAV

现有 `IMediaSeeking` 只写到 `SetPositions`，COM vtable 不完整，`SetRate` 不能调。按 DirectShow 原接口把后面补齐：

- `GetPositions`
- `GetAvailable`
- `SetRate`
- `GetRate`
- `GetPreroll`

打开滤镜图成功后调用 `SetRate`。失败则保持 1.0，状态行提示「当前滤镜不支持倍速」。LAV 分离器 + LAV 音频一般支持 0.5–2.0。

第一版不做变调补偿。快放音调升高，慢放降低。

### 5.3 FFmpeg

`FfmpegPlayer` 呈现等待是 `pts - MediaSeconds(...)`。把时钟流逝乘以 `rate`：

- 无音频时钟时：`origin + clock.Elapsed * rate`
- 有音频时钟时：音频也要按倍率消耗，否则音画再次脱节

第一版做法：视频等待按 `rate` 缩放；音频仍按 48 kHz 写出，但按倍率丢弃或重复 PCM 块（简单抽插），允许音调变化。不做 `rubberband` / `atempo` 滤镜链。

暂停、seek、下一帧不受倍率影响：下一帧始终一帧，不按 2× 跳两帧。

## 6. 音轨

### 6.1 数据

`PipelineInfo` 里已有 `AudioTracks: IReadOnlyList<string>`，只够显示。增加结构化列表：

```csharp
public sealed record MediaTrack(
    int Index,
    MediaTrackKind Kind,
    string Title,
    string? Language,
    bool Selected);

public enum MediaTrackKind { Audio, Subtitle }
```

`IPlaybackEngine` 增加：

```csharp
IReadOnlyList<MediaTrack> GetAudioTracks();
int AudioTrackIndex { get; }
void SetAudioTrack(int index);
```

菜单文案：`Title` 优先，否则「音轨 N」；有语言则加在后面，如 `日语 · Audio 1`。

### 6.2 LAV

`LavPlaybackEngine.ReadStreams` 已经用 `IamStreamSelect` 列出音轨，并知道哪条是「当前」。切换时对同一 group 调 `Enable(index, AMSTREAMSELECTENABLE_ENABLE = 1)`。

LAV Splitter 通常会在图内重接音频。若 `Enable` 成功但声音没换，再走一次「停音频针脚、按新流重连」；这是实现时的兜底，文档里定为第二路径，第一路径是 `Enable`。

### 6.3 FFmpeg

`Open` 现在只用 `av_find_best_stream(AUDIO)`。改为枚举所有 `AVMEDIA_TYPE_AUDIO`，记录 index、`metadata language/title`。

`SetAudioTrack`：

1. 停向 WASAPI 送数，清 `BufferedWaveProvider`
2. 关掉旧 `AVCodecContext` / `SwrContext`
3. 打开新音频流
4. `avcodec_flush_buffers`
5. 从当前视频时间 `av_seek_frame` 一次，避免新音轨从 0 开始

声道仍重采样到 48 kHz stereo s16，输出设备不用重建。

## 7. 字幕

两条引擎最终都把画面变成 BGRA 交给 `VideoPresenter`。字幕不插入 DirectVobSub / XySubFilter，避免依赖本机滤镜。

### 7.1 架构

单独做字幕层，不绑死在某一个引擎上：

1. **列表来源**
   - 内嵌：LAV 用 `IamStreamSelect` 的非视频、非音频流；FFmpeg 用 `AVMEDIA_TYPE_SUBTITLE`
   - 外挂：扫描视频同目录
2. **解码和时钟**
   - 外挂 SRT/VTT/ASS/SSA：自己解析时间轴
   - 内嵌文本（SRT/ASS/mov_text 等）：用 FFmpeg 打开同一文件（LAV 播放时也允许再开一个 demux 只读字幕流）
   - 内嵌位图（PGS、DVD VobSub）：FFmpeg `AVSubtitle` 的 bitmap rect
3. **绘制**
   - 文本：`VideoHost` 上叠加 `TextBlock`（底部居中、描边、最大宽度约画面 80%），不烧进 GPU 纹理。暂停、seek、全屏都跟着走。
   - 位图：把 rect 按画面缩放后画到一帧 overlay 上，或作为 WinUI `Image` 叠在 `SwapChainPanel` 上面。第一版优先叠在 WinUI 层，避免改 D3D 着色器。

播放进度用 `PlaybackController.Position` 每 50–100ms 刷新一次当前字幕事件。seek 后立刻重算。

### 7.2 文本样式（第一版）

- 字体：Segoe UI，默认约 28px，随窗口高度略缩放
- 白色字、黑色描边（四个方向各画一次再画白字，或 `TextBlock` 外一层深色）
- ASS 的 `\pos`、卡拉 OK、特效：**丢掉，只取纯文本**
- 多行保留换行

### 7.3 切换

- 「关闭」：不显示，也不去解码
- 「自动」：外挂优先，否则第一条内嵌文本轨；都没有则等价关闭
- 选某一轨：只显示那一轨
- 「打开字幕文件」：文件选择器，`.srt .ass .ssa .vtt`，当场作为外挂轨并选中

LAV 的 `IamStreamSelect` 对字幕轨可以 `Enable`，但我们不靠它出图。LAV 播放时内嵌字幕走旁路 FFmpeg 读包，避免和 BGRA sink 抢针脚。

### 7.4 失败

外挂解析失败：状态行提示，菜单里该文件标「无法读取」。没有 libass 不算失败。位图字幕解码失败则该轨禁用。

## 8. 画面比例

只改 `VideoPresenter.WriteQuad` 里如何从帧尺寸算四边形。

设舞台像素为 `W×H`，帧为 `Fw×Fh`，目标显示比例为 `A`：

| 模式 | 目标宽高比 | 铺法 |
|---|---|---|
| 适应 | `Fw/Fh` | `scale = min(W/Fw, H/Fh)`，居中，黑边 |
| 填充 | `Fw/Fh` | `scale = max(W/Fw, H/Fh)`，居中，裁掉 |
| 拉伸 | 舞台比例 | 四角贴舞台 |
| 16:9 | 16/9 | 按该比例生成逻辑画面再「适应」进舞台 |
| 4:3 | 4/3 | 同上 |

填充模式必须裁剪，不能把顶点画到 NDC 外面再靠光栅碰运气。实现时把 UV 或顶点夹在舞台内。

`VideoPresenter` 增加 `AspectMode` 属性，`PlayerPage` 菜单改它后 `Refresh()`。

和「自适应窗口」同时打开时：窗口仍按**原始视频比例**去贴合，不按 16:9 强制模式去改窗口，避免窗口和画面两个比例互相打架。

## 9. 截图

`VideoPresenter` 保留最近一次成功提交的 CPU 帧（宽、高、stride、BGRA 拷贝或可复制的纹理回读）。现有路径已经把帧 `Map` 到纹理，最稳的是在 `Submit`/`Draw` 时另存一份小拷贝，截图时编码该拷贝。

编码用 `Windows.Graphics.Imaging.BitmapEncoder` 写 PNG。目录不存在则创建。

截图是当前**显示帧**（含已呈现的视频），不含 WinUI 字幕叠层的话，字幕会丢。第一版接受「截图不含字幕」；若实现时叠层截起来很顺，可以改成含字幕，在实现记录里改一句即可。

## 10. 下一帧

`IPlaybackEngine` 增加：

```csharp
void StepFrame();
```

语义：暂停；若已在暂停，解码并出示下一帧，更新 `Position`。

### 10.1 FFmpeg

循环里已有按包解码。暂停时 `WaitForPresentation` 不送帧。步进：设一个 `_step` 标志，允许解出下一帧视频就 `Deliver`，然后保持暂停。不要把音频灌进 WASAPI。

### 10.2 LAV

滤镜图在 Pause 状态下对 sink 要下一帧。`IMediaSeeking` 用帧格式不一定可用。做法：

1. `Pause`
2. 看 `BgraSink` 是否在暂停后还能收到 sample；收一条就停
3. 若图暂停时不再吐帧，则按 `1/fps` 做一次 `SetPositions` 往前，再 `Pause`

`fps` 从 `PipelineInfo.FrameRate` 来，没有则按 `1/24` 秒。这不是逐帧解码意义上的精确，但 LAV + 自定义 sink 下是可预期的。

没有媒体、或引擎报告失败时按钮禁用。

## 13. 控件栏在全屏 / 无边框下的行为

现有规则保留，只强调几点：

- 经典标题栏：控件栏常驻窗口底部。
- 无边框播放：画面铺满，标题栏和控件栏按鼠标热区出现。
- 全屏：只显示进度条（含左右时间）。按钮行隐藏。快捷键全部仍有效（截图、字幕、倍速等）。
- 全屏不显示置顶、自适应窗口——本来也改不了全屏窗口。退出后按钮状态仍反映设置。

时间移到进度条两端后，全屏进度条也能看见当前/总时长，这是相对现状的改进。

## 14. 引擎接口汇总

`IPlaybackEngine` 在现有 Open/Play/Pause/Stop/Seek/音量/静音/`GetPipeline` 之上增加：

```csharp
double Rate { get; }
void SetRate(double rate);

IReadOnlyList<MediaTrack> GetAudioTracks();
int AudioTrackIndex { get; }
void SetAudioTrack(int index);

IReadOnlyList<MediaTrack> GetSubtitleTracks(); // 仅内嵌；外挂由字幕层管理
```

`PlaybackController` 作为页面唯一入口，转调引擎，并在 `Changed` 里让按钮刷新。字幕外挂、自动匹配、绘制不放进引擎接口，放在 App 层字幕服务，避免 Playback 项目去依赖 WinUI。

截图和画面比例不进引擎，进 `VideoPresenter`。

置顶不进引擎，进 `MainWindow`。

## 16. 实现顺序

按依赖从底向上，避免先摆一排空图标。

1. **样式和现有按钮图标化**  
   打开、停止、上一个、播放、下一个、静音、列表、管线、全屏、自适应窗口。时间移到进度条两端。栏上看起来已经是播放器，能力与现在相同。

2. **把已有逻辑扶上栏**  
   ±5 秒、循环、随机、打开下拉里的 FFmpeg。

3. **置顶、画面比例、截图**  
   不碰解码，先把右侧窗口组做完。

4. **倍速**  
   补 COM 接口和 FFmpeg 时钟。

5. **下一帧**  
   依赖暂停和 seek 已经稳定。

6. **音轨切换**  
   LAV `Enable`，再 FFmpeg 切流。

7. **字幕**  
   最后做。先外挂 SRT + 画面文字叠层，再内嵌文本，再位图轨。

每一步都要能编译运行，控件栏不出现点了没反应的启用按钮。

## 18. 怎么验收

手动，用本地几个典型文件即可：

1. 窗口宽度缩到约 900px：左侧走带可滑，右侧音量和全屏仍在。
2. 播放/暂停图标随状态变；Space 仍有效。
3. ±5 秒与方向键一致。
4. 循环三态、随机开关，栏和列表面板一致。
5. 0.5× 和 2.0×：画面变慢/变快，seek 后仍按该倍率；切到下一文件回到 1.0×。
6. 多音轨文件：菜单列出并切换，声音语言变，进度不归零。
7. 同目录放一个 `.srt`：自动出现字幕；关闭后字消失；`S` 能循环。
8. 截图：目录里有 PNG，能打开且是当前画面。
9. 暂停后连点下一帧：画面往前走，仍暂停。
10. 画面比例：适应有黑边，填充裁切，拉伸变形；自适应窗口仍按片源改窗口。
11. 置顶：切到别的窗口仍浮在上面；全屏再退出后恢复。
12. 全屏：只有进度和时间；`F` / 双击 / Esc 与现在一致；`Ctrl+S` 仍能截图。
