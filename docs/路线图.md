# HomePlayer 产品路线图

本文记录基础播放与媒体库闭环之后可以推进的产品方向、取舍与推荐实施顺序。核心目标不是平铺功能，而是让用户愿意每天打开 HomePlayer，并敢把长期观看记录交给它。本文只描述开发规划，不包含版本或发布承诺。

## 1. 产品定位与阶段判断

HomePlayer 是 Windows 上面向个人本地片库的播放器，不做在线流媒体客户端。当前已具备媒体库分页、目录树、续播、双播放引擎、字幕、音轨、截图、设置和安装发布闭环。

开发围绕三条主线：

1. **日常使用闭环**：继续观看、最近添加、观看状态、个性化播放偏好。
2. **片库可管理性**：批量处理、列表视图、剧集整理、数据备份。
3. **播放质量与可信度**：真实媒体兼容性、字幕音频增强、安装升级验证。

硬解、HDR、完整 ASS 等能力值得推进，但应作为独立的播放引擎专项，不与大量媒体库功能混在同一阶段中。

## 2. 日常使用闭环

阶段主题：**记得你看过什么，也记得你喜欢怎么看。**

实施状态：本节核心需求已完成；明确写为“后续”的项目仍按对应后续阶段推进。

### 2.1 继续观看、最近添加与最近播放

- [x] 继续观看按最近观看时间排序，只显示未看完且进度有效的条目，展示剩余时间。
- [x] 最近添加利用现有入库时间展示最近加入媒体库的内容。
- [x] 最近播放同时覆盖库内视频和通过拖放、文件关联打开的库外视频。
- [x] 支持移除最近播放记录、清空历史，以及暂停记录历史。
- [x] 恢复上次播放列表、当前条目与进度，恢复时不自动播放，避免启动即出声。
- [x] 已提供从头播放入口；续播可配置倒退 0–10 秒。
- [x] 在媒体库中提供浏览模式切换，不重做大型首页，保留现有分页网格。

### 2.2 观看状态与每文件播放偏好

- [x] 支持标记已看、标记未看、从头播放，并可从最近播放移除单条记录。
- [x] 多选支持批量标记已看与未看。
- [x] 每个文件记住音轨、字幕轨、字幕开关、字幕延迟和音频延迟。
- [x] 可选记住音量或倍速，但默认不记住倍速。
- [x] 提供恢复自动选择。
- [x] 优先保存稳定轨道标识或语言偏好，不只保存轨号；文件重封装后轨号可能变化。

### 2.3 字幕基础控制

- [x] 字号、颜色、位置、背景透明度。
- [x] 字幕延迟微调与快捷键。
- [x] 外挂字幕重新加载、手动选择字幕编码。
- [x] 记住每文件字幕偏好。
- [x] 截图可选是否包含字幕。
- [x] 通过 FFmpeg 内置 libass 支持完整 ASS/SSA 排版和字体附件；PGS/VobSub 位图字幕已完成。

### 2.4 数据备份、导出与恢复

- [x] 自动备份数据库和设置，数据库迁移前保留备份。
- [x] 手动导出、导入观看记录与媒体库配置。
- [x] 提供重建缓存维护工具。
- [x] 提供清理孤立记录工具。
- [x] 支持媒体库根目录迁移，保留进度、已看状态与元数据。
- [x] 诊断包包含版本、系统信息、播放管线与最近错误；默认不包含完整媒体路径和 API Key，敏感信息只能由用户明确选择加入。

### 2.5 真实媒体与发布验证

- [x] 使用真实小样本覆盖 FFmpeg 打开、播放、seek、暂停、下一帧、音轨切换、正常 EOF 和解码异常。
- [x] 测试样本优先在构建或测试时生成，不提交大型视频。
- [x] 扩充播放控制器状态机测试，覆盖异常、播放偏好、观看状态与进度保存。
- [x] 补充连续切集、输出设备变化和文件变化等更多状态机场景。
- [x] 增加 1 万、5 万条媒体性能基准，覆盖搜索、翻页、目录树和进度加载。
- [x] CI 构建安装包，并验证安装、启动、文件关联、覆盖升级和卸载。
- [x] 验证旧数据库和设置可升级，发布安装包 SHA256。
- [x] 增加测试版/稳定版通道和应用内更新检查；更新检查先于自动下载更新。
- 已支持可选 Authenticode 签名流程，实际签名仍需要配置有效代码签名证书。

## 3. 片库管理

实施状态：本节规划的管理能力已完成；删除磁盘文件仍不纳入批量移除操作。

### 3.1 列表视图与密度

- [x] 卡片、紧凑卡片和列表三种模式。
- [x] 列表展示标题、时长、分辨率、编码、文件大小、添加时间和观看状态。
- [x] 支持卡片尺寸调节，以及长标题、路径和技术信息之间的显示切换。

### 3.2 多选与批量操作

- [x] 批量加入播放列表。
- [x] 批量标记已看/未看。
- [x] 批量重新处理元数据和封面。
- [x] 批量重新匹配 TMDB。
- [x] 批量从媒体库移除。
- [x] 删除磁盘文件不与“从库中移除”混用；批量移除只处理数据库记录，并明确提示完整扫描可能重新入库。

### 3.3 跨库搜索与组合筛选

- [x] 增加明确的“全部媒体库”搜索范围。
- [x] 支持未看/在看/已看、电影/剧集/未知类型、分辨率、编码、时长、年份、字幕、多音轨、失败和待核对等条件。
- [x] 常用条件集中在一个组合筛选面板中，避免堆叠大量筛选按钮。

### 3.4 收藏、标签与自定义合集

- [x] 实现轻量收藏，支持单条切换、批量收藏与取消、独立收藏浏览。
- [x] 标签支持批量编辑和组合筛选，数据库迁移保留关联数据。
- [x] 自定义合集区分手动成员合集与智能规则合集，可创建、删除、批量加入和筛选。

### 3.5 剧集与元数据

第一层是不依赖复杂元数据的剧集导航：

- [x] 按季集字段和自然数顺序排序。
- [x] 播放页提供上一集/下一集与播完自动连播。
- [x] 支持手工修正季集编号。

第二层是剧集聚合：

- [x] 一部剧一张卡片，按季浏览，显示整剧进度和下一集未看。
- [x] 支持系列电影合集。
- [x] 支持手工匹配与编辑标题、年份、海报和简介。
- [x] 支持本地 NFO 和海报，降低对 TMDB 的依赖。
- [x] 覆盖多版本、特别篇、OVA、合集文件和跨季目录等边界情况。

## 4. 播放质量与引擎专项

### 4.1 内容导航

- [x] 进度条悬停显示目标时间、缩略图预览。
- [x] 章节列表、章节跳转和书签。
- [x] 自定义快进快退步长及大步骤跳转。
- [x] A-B 循环。

### 4.2 音频体验

- [x] 音轨语言偏好和音频延迟。
- [x] 倍速保持音调。
- [x] 保留多声道，不再固定降为双声道。
- [x] 音量归一化、夜间模式。
- [x] 音频设备断开后自动回退并提示。
- [x] 多声道同时处理重采样、WASAPI 格式和音频时钟。

### 4.3 字幕能力

- [x] 通过 FFmpeg 内置 libass 支持 ASS 排版、样式表、复杂特效和字体回退。
- [x] PGS/VobSub 位图字幕。
- [x] 两条播放引擎共用字幕会话与呈现层。
- [x] 截图可选包含字幕。

### 4.4 硬解、HDR 与现代编码

- 探索 D3D11VA/DXVA2 硬件解码。
- 优化 H.265、AV1、VP9 高码率播放。
- 减少硬件解码帧到 D3D11 呈现层的拷贝。
- 支持 HDR10 元数据和 HDR→SDR 色调映射。
- 处理可变帧率、旋转信息、非方形像素和异常时间戳。
- 硬解失败后透明回退软解，保留当前稳定路径。

实施前建立性能基线：1080p/4K，H.264/H.265/AV1，CPU/GPU/内存，首帧时间、seek 响应、丢帧和音画同步。不要把全面重写播放引擎作为其他阶段的附带任务。

## 5. 持续方向

### 5.1 媒体库自动维护

- [x] 文件系统监听自动触发扫描，新增文件自动入库。
- [x] 监听后的文件和目录变化按路径增量处理，减少全量枚举。
- [x] 网络盘和可移动磁盘离线或部分目录不可读时保留现有条目与观看进度，不误判删除。
- [x] 明确展示媒体库暂时不可用/离线状态，并在恢复后自动重建监听和扫描。
- [x] 展示扫描阶段、数量、失败目录列表和重试入口。

### 5.2 性能与可靠性

- [x] 建立 1 万、5 万条媒体的大库基准。
- [x] 持续跟踪首帧、翻页、搜索、目录树、进度加载和缓存的耗时与内存，并写入诊断包。
- [x] 保留完整扫描失败保护、错误与空态区分、原子设置保存和观看进度安全。

### 5.3 发布与更新

- [x] CI 已覆盖安装、启动、文件关联、覆盖升级和卸载自动化验证。
- [x] 发布已包含 SHA256 校验和与变更说明，应用内可查看播放管线和崩溃诊断信息。
- [x] 增加测试/稳定通道和应用内更新检查。
- 已支持可选 Authenticode 签名流程，实际签名仍需要配置有效代码签名证书。

## 6. 暂不纳入近期规划

- 云同步与账号体系。
- 在线流媒体客户端能力。
- 大型首页重做。
- 自动更新器先于更新检查落地。
- 在缺乏性能基线时全面重写播放引擎。

## 7. 剩余事项推荐顺序

1. **实际代码签名**：配置有效证书及仓库 secret，验证应用与安装包签名；签名流程已经接入构建。
2. **硬解、HDR 与现代编码专项**：按用户决定单独实施，不与其他功能混合推进。
