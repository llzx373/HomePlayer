# HomePlayer 播放引擎路线与轨道实施记录

本文记录“路线事务与稳定轨道身份”的逐条目实施状态。每项独立提交；先关闭旧会话的降级模式不得描述成新旧会话并存或可完整回滚。

## 条目 1：稳定音轨与字幕身份

实施内容：

- `MediaTrack` 增加 `StableId` 和 disposition。FFmpeg 优先使用容器流 UID；没有 UID 时使用轨道类型、语言、标题和 disposition 生成元数据身份。LAV 当前使用元数据身份，不把内部启用标志误当成 disposition。
- `MediaPreference` 增加可空音轨/字幕 StableId，数据库 Schema 升级到 v9。旧字段和旧偏好继续保留，迁移只增加可空列。
- 偏好恢复依次尝试 StableId、标题与语言、唯一语言和原轨号。任何一层出现多个候选都停止恢复并保留自动选择，不再任意选第一条；重排序后的唯一 UID 可命中新轨号。
- 音轨与内嵌字幕共用选择逻辑，清除音轨偏好同时清除 StableId。

验证：

- 确定性测试覆盖重封装式轨号重排、重复 StableId 和同语言歧义。
- 真实双音轨媒体的 StableId 非空且不同；MediaPreference 含 StableId 的读写与更新通过，Schema v9 新库和旧库迁移通过。
- `dotnet test HomePlayer.slnx --configuration Release`：Core 248、Playback 59、Library 53，全部通过。
- `dotnet build src/HomePlayer.App/HomePlayer.App.csproj --configuration Release`：0 警告、0 错误。

边界：

- 歧义时目前保留自动选择，尚未增加要求用户手动确认候选的对话框；不会把歧义当成成功恢复。
- LAV 没有容器 UID 来源时只能使用元数据身份，重封装后相同元数据的多轨仍需要用户重新选择。

状态：稳定音轨与字幕身份已完成，后续继续路线切换 OperationId 与 prepare/commit/abort 降级事务。
